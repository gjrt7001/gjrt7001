歡迎來到我的 GitHub 頁面！我是一名專職的**資料分析師 (Data Analyst)**，同時也是一名**資料工程師 (Data Engineer)**。

## 👨‍💻 關於我 (About Me)
我擅長處理與分析複雜的數據。透過結合資料工程的底層架構技術與資料分析的商業敏銳度，我致力於將原始數據轉化為有價值的商業決策依據。

## 🛠 程式與工具 (Skills & Tools)

### 程式技術 (Programming)
*   **Python**：熟悉資料處理、爬蟲、自動化與數據分析。
*   **SQL**：精通複雜查詢、資料表設計與效能優化。

### 分析與資料庫工具 (Tools)
*   **Power BI**：擅長商業智慧報表開發與資料視覺化儀表板建置。
*   **SSMS (SQL Server Management Studio)**：用於 SQL Server 資料庫的管理、開發與維護。
*   **SSAS (SQL Server Analysis Services)**：熟悉資料倉儲模型構建與多維度資料分析。
